## Задача

Разработать Python-пакет `toolkit` с консольным интерфейсом,
содержащий калькулятор арифметических выражений и конвертер единиц
измерения.

## Возможности

### Калькулятор

- Четыре операции: `+`, `-`, `*`, `/`, `%`, `//`,
- Приоритет операций (`*`, `/`, `%` и `//` раньше `+` и `-`)
- Унарные `+` и `-` перед числом (включая `++7` и `--7`)
- Игнорирование пробелов между токенами
- Целые и вещественные числа
- Игнорирование незначащих нулей (000123 = 123)
### Конвертер

- Длина: `mm`, `cm`, `m`, `km`
- Масса: `g`, `kg`
- Температура: `c`, `f`, `k`
- Регистр единиц не важен
- Конвертация между разными группами запрещена
- Температура ниже абсолютного нуля запрещена

### Обработка ошибок

- Все пользовательские ошибки выводятся в `stderr`
- Код возврата при ошибке — `2`
- Код возврата при успехе — `0`
